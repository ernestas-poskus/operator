# Fixture attributions

`office.docx`, `slides.pptx`, `sheet.xlsx`, `text.rtf` and `document.odt` are
test documents from [Apache Tika](https://github.com/apache/tika), used under
the Apache License 2.0. They were copied unmodified from Tika's parser test
resources (`tika-parser-microsoft-module` and `tika-parser-miscoffice-module`);
see `THIRD_PARTY_NOTICES.md` at the repository root and
<https://www.apache.org/licenses/LICENSE-2.0>.

`note.pdf` and `scanned.pdf` are generated by `bench/doc-router/make_fixtures.py`
from a short text written for this repository, then exported and rasterised
locally; they carry no third-party content.

`manifest.json` records each file's SHA-256 so a swapped fixture fails the
router test instead of silently changing what it proves.
