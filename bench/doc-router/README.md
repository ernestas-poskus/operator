# Document-router snapshot experiment

Frozen test data and harness for the `anydoc` vs `xberg` routing decision in
[`src/document.rs`](../../src/document.rs). The policy is documented in
[`docs/document-router.md`](../../docs/document-router.md).

## What is frozen

`snapshot.json` pins the input set:

* **507 documents** (501 timed, 6 oversized reliability-only) across 17 formats,
  each identified by SHA-256.
* Two corpora: `xberg-io/test_documents` at the revision its `main` references,
  and Apache Tika's parser test resources. Both are sampled per format so no
  single vendor's corpus can dominate a format.
* Pins: anydoc 0.2.4, xberg 1.3.10, the two corpus commits, the `Cargo.lock`
  hash, the rustc version and the host.

`golden/` holds the verdict and its evidence:

* `route.json` — the routed engine per extension, the rule, and the per-format
  statistics that produced it.
* `per_doc.jsonl` — every document's outcome, latency and F1 under both engines.
* `summary.json`, `truth_hashes.json` — per-format aggregates and the hashes of
  the independently extracted ground truth.

`fixtures/` holds seven small documents (Tika, Apache-2.0, plus two generated
PDFs) used by the offline `tests/document_router.rs`; `fixtures/manifest.json`
hashes them.

## Reproduce

```sh
# 1. materialize + verify the corpus (~540 MB, public sources, hash-checked)
python3 bench/doc-router/fetch.py
python3 bench/doc-router/fetch.py --verify-only     # offline

# 2. run both engines and the shipped router over the timed documents
python3 bench/doc-router/run.py                     # --reps 3 --warmup 1

# 3. score against independent ground truth (PyMuPDF for PDF text layers;
#    LibreOffice for legacy binary formats)
uv run --with pymupdf python bench/doc-router/score.py

# 4. derive the table from the measurements, then check it
python3 bench/doc-router/derive.py
python3 bench/doc-router/derive.py --check          # exit 1 on drift
python3 bench/doc-router/derive.py --update         # rewrite golden/
```

A full run is roughly 10 minutes of conversion plus scoring; `run.py` uses a
release build. `--no-release` trades timing accuracy for build time.

`run.py` passes `cargo-override.toml` because this host's global cargo config
forces `lto = true`, `panic = "abort"`, `codegen-units = 1` and `jobs = 64`.
The override restores an ordinary release profile; `panic = "unwind"` is
required, otherwise one corrupt `xlsb` aborts the whole xberg run (and the
router's per-document isolation with it).

`fetch.py --archive out.tar.gz` writes a portable corpus archive for machines
that cannot reach the public bucket.

## Layout

```
snapshot.json        frozen documents, selection parameters and pins
fetch.py             materialize + verify + archive
run.py               drive examples/docbench over the snapshot
score.py             ground truth, token F1, per-format speed
derive.py            rule -> golden/route.json (--check / --update)
make_snapshot.py     regenerate snapshot.json from a fresh benchmark checkout
make_fixtures.py     regenerate fixtures/ (Tika copy + generated PDFs)
golden/              frozen verdict and evidence
fixtures/            small committed documents for the offline tests
.cache/              fetched corpora and truth text (gitignored)
results/             raw JSONL, outputs and scores (gitignored)
```

## Rules

* Only files whose SHA-256 matches `snapshot.json` are used; a mismatch or a
  missing file fails the run instead of silently shrinking the corpus.
* Ground truth is extracted independently of both engines (container XML,
  PyMuPDF, LibreOffice). Its hash is recorded, so a different LibreOffice build
  reports truth drift rather than changing the scores quietly.
* Extension verdicts inherit their parser family (`docm`→`docx`,
  `pptx` family, `xlsm`→`xlsx`, `xlsb`/`dot`→base) when the snapshot has too few
  documents to decide them independently.
* Changing the routed table requires re-running the experiment, updating
  `golden/`, and bumping `document::ROUTER_REVISION` so the document corpus
  re-embeds.

## Licensing

The corpus is not redistributed here. `fetch.py` downloads it from its public,
hash-addressed sources; `snapshot.json` carries each document's license note.
The committed fixtures are Apache-2.0 (see `fixtures/ATTRIBUTIONS.md`) or
generated by `make_fixtures.py`.
